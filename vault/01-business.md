# Business Context & Goals

## The Product
**Autonomous Engineering & Growth CLI (AEG)**

A specialized command-line interface tool (`aeg`) that leverages a Multi-Agent System (MAS) to autonomously perform **SEO (Search Engine Optimization), AEO (Answer Engine Optimization), and GEO (Generative Engine Optimization)** directly on your codebase.

## Core Philosophy
**AI is NOT the source of truth.**
`FACT → TOOL → EVIDENCE → AI ANALYSIS → DECISION → EXECUTION → VERIFICATION`

The system demands concrete evidence (Lighthouse scores, Schema.org validation, GSC indexing status) before allowing an AI to make decisions or commit code.

## Key Objectives
1. **Technical SEO Dominance:** Automate Core Web Vitals fixes, sitemap generation, and instantaneous search engine indexing (IndexNow/GSC).
2. **AEO & Semantic Web:** Auto-inject perfect JSON-LD, Microdata, and OpenGraph tags so Answer Engines (Google AI Overviews) can instantly extract facts.
3. **GEO (Generative Engine Optimization):** Structure content architecture and semantic relevance so AI models (ChatGPT, Perplexity, Claude) rank the pages highly in their context windows.
4. **Safety & Zero-Downtime:** Keep production safe. Agents operate in dev/test sandboxes, isolated via Git worktrees, requiring human or Truth Gate verification to merge.
